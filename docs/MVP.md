# Current scope: Мешок Деняк

Проект начинался как MVP, но текущая реализация уже включает аккаунты, Postgres, real-time через WebSocket, историю партий, профиль игрока, production-конфиги и integration tests. Этот документ фиксирует текущую границу продукта: что уже реализовано, что остаётся за пределами текущей версии и что логично делать дальше.

## Что входит сейчас

- Регистрация, вход, выход, logout со всех устройств.
- Сессии в cookie, хранение сессий в Postgres.
- Подтверждение email и сброс пароля через токены. В dev-режиме токены возвращаются API-ответом; для production нужна реальная отправка email.
- Комнаты с кодом и ссылкой-приглашением.
- Публичные и приватные комнаты.
- До 4 игроков в одной комнате.
- Роль хоста: настройки комнаты, старт партии, рестарт, кик игрока из лобби, передача хоста, архивирование.
- Роль зрителя.
- Список публичных и своих комнат.
- Выбор стартовой профессии.
- Очередность ходов, бросок кубика и игровое поле.
- Первый круг `Денежный двор`: зарплата, возможности, расходы, рынок, благотворительность, сокращение.
- Малые и крупные сделки, покупка за наличные или с кредитом, пропуск сделки.
- Закрытие обязательств из финансового отчёта.
- Рыночные предложения на продажу активов.
- Репутация и переход в `Лигу проектов`.
- Проектный круг: деньги, бизнес, рынок, цель, благотворительность, налоги.
- Проектные сделки, обслуживание проектных активов и чистый поток проектов.
- Победа через личную большую цель.
- Победа через устойчивый портфель проектов.
- Победа по капиталу при лимите ходов.
- Долговые guardrails: финансовый стресс, автоликвидация актива, реструктуризация и банкротство.
- Чат комнаты.
- Real-time обновление комнаты через WebSocket с heartbeat, reconnect и HTTP fallback polling.
- Сохранение комнат, аккаунтов, сессий и истории игр в Postgres.
- Профиль игрока, статистика, история партий и публичный профиль.
- Единый серверный источник поля и профессий через `/api/rules`.
- Unit tests для правил, balance simulator tests, API/integration tests с тестовой Postgres.
- CI на GitHub Actions с Postgres service.
- Dockerfile, Render blueprint, healthcheck, production env example, security headers, structured logging, graceful shutdown, backup/restore scripts.

## Что пока не входит

- Реальный production deploy, домен и HTTPS.
- Реальная отправка email через SMTP/Resend/Postmark/etc.
- Sentry/log drain и production alerting.
- Managed backups у провайдера и проверенный restore drill.
- Browser e2e tests.
- Админка и support tooling.
- Модерация чата, имён и названий комнат.
- Privacy settings для публичного профиля.
- Горизонтальное масштабирование WebSocket/presence.
- Seeded RNG и replay/event log для воспроизводимости партий.
- Платежи, рейтинги, matchmaking, турниры.
- Terms of Service, Privacy Policy, account deletion/export.

## Текущий баланс

- Профессий: 10.
- Стартовый свободный остаток профессий: примерно от `$860` до `$1420`.
- Стартовые долги профессий: примерно от `$7,200` до `$15,400`.
- Переход в Лигу проектов: 5 репутации и денежный резерв на 2 месяца расходов.
- Стоимость больших целей: примерно от `$13,500` до `$17,200`.
- Целевой доход проектов для альтернативной победы: `$6,200`.
- Минимальный портфель для альтернативной победы: 3 проекта.
- Длины игры: быстрая, стандартная, без лимита.
- Режимы победы: классика, большая цель, портфель проектов, капитал к лимиту ходов.

## Запуск

Локально нужен Node.js 18+ и Postgres. Самый простой путь:

```bash
npm install
npm run db:up
npm start
```

После запуска:

```text
http://localhost:3000
```

Healthcheck:

```text
http://localhost:3000/api/health
```

## Проверка

```bash
npm test
```

Полный integration-прогон с Postgres:

```powershell
$env:TEST_DATABASE_URL='postgres://cashflow:cashflow@localhost:15432/cashflow_online'
npm test
```

Быстрый прогон баланса:

```bash
npm run simulate -- --games=80 --players=4 --seed=42 --length=quick --victory=classic
```
