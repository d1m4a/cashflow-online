# MVP: Денежный поток онлайн

## Что входит

- Комнаты с кодом для подключения.
- До 4 игроков в одной комнате.
- Очередность ходов и бросок кубика.
- Поле из 18 клеток: зарплата, возможности, расходы, рынок, благотворительность, сокращение.
- Базовый финансовый отчёт игрока: наличные, пассивный доход, расходы, активы.
- Сделки, которые можно купить или пропустить.
- Условие победы: пассивный доход игрока стал не меньше расходов.

## Что сознательно не входит в первый MVP

- Регистрация и постоянные аккаунты.
- WebSocket-синхронизация.
- Сохранение комнат после перезапуска сервера.
- Полные правила настольной игры.
- Платежи, рейтинги, чат и модерация.

## Запуск

```bash
npm start
```

После запуска открой:

```text
http://localhost:3000
```
