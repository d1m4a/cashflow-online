# MVP: Денежный поток онлайн

## Что входит

- Комнаты с кодом для подключения.
- До 4 игроков в одной комнате.
- Стартовые профессии: инженер, учитель, врач, водитель, дизайнер.
- Очередность ходов и бросок кубика.
- Поле из 18 клеток: зарплата, возможности, расходы, рынок, благотворительность, сокращение.
- Расширенный финансовый отчёт игрока: наличные, доходы, расходы, денежный поток, пассивный доход, обязательства, активы.
- Выбор малой или крупной сделки при попадании на возможность.
- Малые и крупные сделки, которые можно купить за наличные, купить с кредитом или пропустить.
- Закрытие обязательств из финансового отчёта.
- Рыночные предложения на продажу активов.
- Чат комнаты.
- Real-time обновление комнаты через Server-Sent Events.
- Условие победы: пассивный доход игрока стал не меньше расходов.
- Единый серверный источник поля и профессий через `/api/rules`.
- Тесты основных действий финансовой модели.

## Что сознательно не входит в первый MVP

- Регистрация и постоянные аккаунты.
- Полноценная WebSocket-синхронизация с двусторонним каналом.
- Сохранение комнат после перезапуска сервера.
- Полные правила настольной игры и точный баланс оригинальной механики.
- Платежи, рейтинги и модерация.

## Запуск

```bash
npm start
```

После запуска открой:

```text
http://localhost:3000
```
