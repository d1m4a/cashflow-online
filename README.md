# Cashflow Online MVP

Минимально жизнеспособный прототип онлайн-игры "Денежный поток" с комнатами, ходами, сделками и базовой финансовой моделью.

## Возможности MVP

- Создание комнаты и подключение по коду.
- До 4 игроков в комнате.
- Очередность ходов, бросок кубика и игровое поле.
- События: зарплата, возможность, расход, рынок, благотворительность, сокращение.
- Сделки с покупкой или пропуском.
- Real-time обновление комнаты без ручного обновления страницы.
- Условие победы: пассивный доход стал не меньше расходов.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm start
```

После запуска открой:

```text
http://localhost:3000
```

Для проверки мультиплеера создай комнату и открой второй браузер или вкладку в приватном режиме.

## Структура проекта

- `backend/server.js` - HTTP-сервер, API комнат и раздача frontend.
- `frontend/index.html` - разметка лобби и игрового экрана.
- `frontend/app.js` - клиентская логика и обновление интерфейса.
- `frontend/styles.css` - тёмная UI-тема по игровому макету.
- `shared/gameRules.js` - правила, состояние игры и действия игроков.
- `docs/MVP.md` - границы текущего MVP и план развития.
